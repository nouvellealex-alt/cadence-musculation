# Contribuer à Cadence

Lancez `python -m http.server 8764 --bind 127.0.0.1 --directory dist`, puis ouvrez http://127.0.0.1:8764/. En production, servez `dist/` en HTTPS. Le code fonctionne sans compilation et sans clé.

- Pour signaler un problème, indiquez le navigateur, la version de Cadence, les étapes et le résultat. Utilisez un carnet fictif pour les captures et fichiers joints.
- Pour une correction, préservez les identifiants du catalogue et les champs d’anciennes sauvegardes. Un changement de schéma doit inclure une migration ou des valeurs par défaut. Testez aussi le rechargement hors ligne si vous ajoutez un fichier applicatif.
- Pour proposer un exercice, indiquez le nom français, les synonymes, le matériel, le groupe principal, le type de suivi et une consigne rédigée pour Cadence. Vérifiez les variantes et doublons.
- Pour proposer un média, indiquez le fichier source, son auteur, la licence exacte et les modifications. Seules les ressources redistribuables ont leur place dans cette édition. Les références de fournisseurs sous licence fermée restent hors de l’application.
- Si un signalement contient des données personnelles ou une vulnérabilité exploitable, retirez ces détails du ticket public.

Le code Cadence est distribué sous AGPL-3.0-only. Consultez les crédits séparés pour les médias tiers.
